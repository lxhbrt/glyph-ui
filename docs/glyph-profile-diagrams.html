Glyph — Agent-Profile

Warum die Teile hinzugefügt wurden & wie jedes System funktioniert. Eingebettete SVG-Diagramme (Skalierbar, keine externen Assets, hell/dunkel).

0 · Strategie — warum welches Profil

GrundideeGlyph ist ein ACP-Client, kein Modell-Client. Jedes Profil spawnet einen anderen Agenten/Adapter. Die Profile decken bewusst drei verschiedene Bestandsquellen ab, damit nie ein einzelner Anbieter zum Blockierer wird.

Der Grund für die Mischung: grok & claude = vorhandene OAuth-Logins · glyph-agent = lokale Vault/Tools-Schicht mit Cloud-Antwort in der Engine (Technik-Provider nur in Config, nicht als UI-Profil).

1 · grok — OAuth-Ablauf

Warum ergänztStandard-Profil & UI-Heart: gespeichert unter ~/.grok/sessions, volle Fähigkeiten (Sessions, Deep Search, Aktivität) — das TUI-Erlebnis im Browser.

2 · claude — OAuth + ACP-Adapter

Warum ergänztZweites OAuth-Konto (neben grok) für den Anthropic-Chat innerhalb des vorhandenen Logins. Sessions liegen unter ~/.claude/projects — daher in Glyph nicht in der Session-Liste/Aktivität.

Hinweis: claude-agent-acp ist aktuell nicht global installiert — das Profil lädt es erst via npx -y. Für Offline-Betrieb oder schnellere Starts: npm i -g @agentclientprotocol/claude-agent-acp.

3 · glyph-agent — Vault, Tools & Cloud-Antwort

Warum ergänztEigene Engine hinter dem Profil: VaultFind (lokal), Web nur bei Bedarf, dann Cloud-Antwort in der Engine. Kein separates Cloud-UI-Profil — Technik-Provider nur in Config/CONSTITUTION.

4 · Cloud-Antwort (nur in glyph-agent, kein UI-Profil)

Warum ergänztZentrale Tür zu vielen Cloud-Modellen (DeepSeek, Llama, …) über einen einzigen API-Key — zum Testen/Anbinden weiterer KIs, ohne je ein eigenes Konto pro Anbieter zu brauchen.

5 · Ziel-Architektur im Überblick

GesamtbildEin Gesicht (Glyph), drei Profile dahinter — unabhängig, sodass „Anbieter X down“ die anderen nicht berührt. glyph-agent = Vault/Tools + Cloud-Antwort in der Engine; grok/claude = OAuth-Cloud-Chats.

Prio: Vault/Recherche → glyph-agent. Breite Kontextarbeit/Sessions → grok oder claude im Dropdown.
